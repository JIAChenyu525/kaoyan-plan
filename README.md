# 考研备考路线图

武汉理工大学应用统计学（2028 考研）的备考时间轴，单页静态 HTML。

线上地址：https://jiachenyu525.github.io/kaoyan-plan/

## 页面里有什么

- **四科时间轴**：数学 / 英语 / 专业课 / 政治，2026.09 – 2027.12 共 16 个月。电脑上是横向甘特图，手机上自动切换成竖版（月份往下走，五列并排）。色块可以直接点，点一下就是标记完成。
- **今日**：按打开页面的当天日期，显示你在哪个备考阶段、第几天、距初试多少天，以及一句对应阶段的提醒。同一天刷新不变，跨天自动换；阶段一变，整组句子跟着换。页面一直开着跨过午夜也会自动更新（切回标签页时查一次，平时每分钟查一次，日期变了就重载）。
- **现在在跑**：今日卡片下半部分，按当天日期自动列出正在进行的阶段，每个带一个阶段色的圆点。纯展示，不能勾——要勾选走下面的明细表或直接点时间轴色块。
- **每科明细**：各阶段的时间、任务、用书清单。每行右侧有一个勾选框。当前所处的阶段那一行会有浅色底和「现在」标记。
- **打勾进度**：勾选框的状态存在浏览器 localStorage 里（键名 `kaoyan-progress-v1`），关掉浏览器再开还在。勾上之后，时间轴上对应的色块会一起褪色，顶部进度条和每科标题右上的 `x / n` 同步更新。

如果打不开 localStorage（某些浏览器不允许本地文件存数据），页面上会直接显示一行提示说明打勾不会被记住，而不是假装记住了。

## 字体

页面**不请求任何外部资源**。原来从 Google Fonts 取字体，那套 CDN 国内取不到，会静默回退成系统字体，设计就废了一半。现在七个字体文件（Noto Serif SC / Noto Sans SC / IBM Plex Mono 各自的用到的字重）已经按页面实际用到的字符做了子集，base64 内嵌在 HTML 里，所以 `index.html` 有 800 KB 左右——这是正常的，不是哪里出错了。

**改了页面文字之后**（加语录、改阶段名、改任务描述）要重新跑一次子集化，否则新出现的字会掉回系统字体：

```
python _tool/embed_fonts.py
```

脚本是幂等的，重跑会先摘掉旧的字体块再重新生成；字体源缓存在 `_tool/_work/`，不会重复下载 40 MB。

## 改哪里

`index.html` 里三个数据块，改完刷新即可：

| 位置 | 作用 |
|---|---|
| `PHASES` | 备考阶段划分和每个阶段的语录库 |
| `LANES` | 时间轴上的色块（起止月份、标签、悬停说明） |
| `SUBJECTS` | 下方四科的明细表格和材料清单 |

初试日期写在 `EXAM` 常量里，官方日期出来后改这一处。

**打勾状态是按「第几科的第几行」记的**（`s0-3` 这种键）。所以在某个科目里插行、删行或调换顺序，已经勾好的状态会跟着错位——改完结构后自己重新勾一遍就行。

时间轴色块和明细行之间靠阶段名对应（`phaseKey()`）。政治的色块用的是简称（`强化课` / `模拟卷`），走了 `LABEL_ALIAS` 别名表。**新增或改名阶段时，要么两边标签写成一样的，要么把简称补进别名表**，否则那个色块不会跟着勾选状态变灰。

## 桌面快捷方式

`icon.ico` 是桌面快捷方式「考研规划」用的图标，和页面 favicon 是同一套图形。
快捷方式指向本目录下的 `index.html`，双击用默认浏览器打开。

色板经过色盲安全校验，明暗两套主题都单独配过色，改动颜色时请保持同一套 token。
