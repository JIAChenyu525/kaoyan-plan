# 考研备考路线图

武汉理工大学应用统计学（2028 考研）的备考时间轴，单页静态 HTML。

线上地址：https://jiachenyu525.github.io/kaoyan-plan/

## 页面里有什么

- **四科时间轴**：数学 / 英语 / 专业课 / 政治，2026.09 – 2027.12 共 16 个月。电脑上是横向甘特图，手机上自动切换成竖版（月份往下走，五列并排）。
- **今日**：按打开页面的当天日期，显示你在哪个备考阶段、第几天、距初试多少天，以及一句对应阶段的提醒。同一天刷新不变，跨天自动换；阶段一变，整组句子跟着换。
- **每科明细**：各阶段的时间、任务、用书清单。

## 改哪里

`index.html` 里三个数据块，改完刷新即可：

| 位置 | 作用 |
|---|---|
| `PHASES` | 备考阶段划分和每个阶段的语录库 |
| `LANES` | 时间轴上的色块（起止月份、标签、悬停说明） |
| `SUBJECTS` | 下方四科的明细表格和材料清单 |

初试日期写在 `EXAM` 常量里，官方日期出来后改这一处。

色板经过色盲安全校验，明暗两套主题都单独配过色，改动颜色时请保持同一套 token。
